# Илья

Разрабатываю приложения и сервисы с ИИ.

Занимаюсь серверной логикой, интерфейсами, обработкой документов и подключением моделей. Запускаю проекты на сервере и продолжаю их дорабатывать.

## Проекты

### [Ai-Expert · Эксперт ПД](https://github.com/ilya-baylov/ai-expert-pd)

Проверяет проектную документацию перед подачей: находит расхождения, показывает исходные страницы и собирает замечания в отчёт.

Собрал обработку документов, проверки, Telegram-бота и веб-приложение. Числовые проверки выполняются отдельными правилами; модели используются для разбора текста и изображений. У результатов сохраняются источники и версии документов.

[Открыть бота](https://t.me/aiexpertproject_bot) · [Посмотреть примеры](https://github.com/ilya-baylov/ai-expert-pd#примеры-проверки)

### [ИИ-помощник](https://github.com/ilya-baylov/knowledge-assistant)

Внутренний помощник для сотрудников: отвечает по документам компании, принимает голосовые вопросы и учитывает контекст разговора.

Собрал загрузку документов, поиск, подготовку ответов и управление доступом. В поиске объединены эмбеддинги и точные совпадения, чтобы находить как свободные формулировки, так и конкретные термины. Есть тесты обработки документов, поиска и работы бота.

[Исходники и запуск](https://github.com/ilya-baylov/knowledge-assistant#запуск) · [Тесты](https://github.com/ilya-baylov/knowledge-assistant/actions/workflows/tests.yml)

## С чем работаю

Python, JavaScript, FastAPI, aiogram, SQL, SQLite, API языковых моделей. В проектах занимаюсь поиском по документам, распознаванием текста, интеграциями и развёртыванием на Linux.
